Best Practices

Hierarchy

  • One h1 per page, main title only
  • Never skip heading levels
  • Use .body-l for primary content

Readability

  • 50–75 characters per line
  • Body styles meet 1.5× min line-height
  • Use Neutral.700 on light surfaces

Weights

  • 400 — body & caption text
  • 600 — buttons, h2–h4, UI labels
  • 700 — h1 only
  • Max 3 weights per screen

Mobile Scaling (−15%)

  • h1: 27px / 34px lh
  • h2: 20px / 28px lh
  • h3: 17px / 24px lh
  • body-l: 14px / 20px lh

Best Practices

Scale

  • Always scale uniformly
  • Never stretch or skew
  • Use SVG — never rasterize

Consistency

  • Keep stroke at 2px across a view
  • Don't mix stroke weights
  • One icon style per product

Meaning

  • Use universal icon meanings
  • Add label when ambiguous
  • Icons serve function, not decor

Accessibility

  • Min tap target: 40×40px
  • Add aria-label or tooltip
  • Don't rely on color alone

WCAG Usage Rules

Text Guidelines
  • Body text: Neutral-800 / 900 on light backgrounds
  • Links: Brand-700+
  • Status text: 700+ on light BG, 500+ for fills
  • Avoid text on Brand-500 — insufficient contrast
Button & Component Guidelines
  • Buttons: White text only on 600+
  • Primary CTA: Use Brand-950 with white text
  • Icons/Focus: Brand-500 for accents
  • Disabled states: Neutral-300/400
Contrast Requirements
Text TypeAAAAA
Normal text (under 18pt)4.5:17:1
Large text (18pt+ or 14pt+ bold)3:14.5:1
UI components & focus indicators3:1 minimum—
Best Practices
  • Test all color combinations with a contrast checker
  • Never rely on color alone to convey information
  • Validate hover and focus states separately
  • Consider colorblind users — use patterns/icons in addition to color

  • Separate major layout sections with 32 px
  • Keep icon-to-label gap at exactly 8 px

  • Use arbitrary pixel values (e.g., 13 px, 22 px)
  • Mix padding directions inconsistently within a card
  • Use more than 32 px gap inside a single card section
  • Set the page content padding below 20 px
  • Apply different gaps to visually equivalent rows
  • Nest cards without any inner spacing separation

Usage Guidelines

  • Always show exactly one metric per card — do not stack multiple values.
  • Use the IconFrame icon to hint at the metric type (e.g. bar-chart for programs, users for participants).
  • Trend text is optional — omit if no comparison period is available.
  • Use success-500 (#17B26A) for positive trends, error-600 (#D92D20) for negative.
  • Cards should be laid out in a 3-column grid on desktop, 1-column on mobile.
  • Never use coloured backgrounds — KPI cards are always white.
  • Hover state: lift translateY(-2px) + deeper shadow. Always add transition.

  • Always white background — never tinted or coloured (coloured = Category Icons).
  • Always primary-600 blue (#1570EF) for the icon — no other colours.
